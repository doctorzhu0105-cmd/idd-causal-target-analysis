# v1.3.0 — R1 repository update (draft)

## Planned additions

- R1 source-adapted components and four independent numerical verifiers for saved A/B, fixed-W rho, FE/RE regime and PSD/Schur comparisons.
- A synthetic fixture and aggregate matched-set evidence census.
- Documentation distinguishing 6,087 historical complete matrix results from 1,068 conditional K1 scalar reconstructions based on C3 inputs marked COMPUTED_UNVERIFIED.
- Explicit accounting for 7,155 conditionally evaluable comparisons, 129 incomplete comparisons with UNKNOWN matched-set precision and 150 separate missing membership configurations. The 129 consist of 54 empty common sets, 51 non-empty sets with missing high-threshold cache, and 24 non-empty sets with missing low-threshold cache.

## Boundaries

The 1,068 keyed derived rows and restricted inputs are not included pending provider/file-level redistribution review. The 25 RE and 6 FE direction changes refer to the 6,087 historical complete comparisons. The validators are not the original analysis generators, and complete end-to-end historical reconstruction is not claimed. Historical v1.2.0 files, its tag and commit remain preserved. This text is a local draft; actual release identity and any version DOI must be checked after publication.
