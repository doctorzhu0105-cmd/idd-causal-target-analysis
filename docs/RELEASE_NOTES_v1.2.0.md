## Preserved

## Boundaries

This release does not introduce a new estimator, validate an adequacy score, provide independent replication, or validate therapeutic targets. No restricted raw third-party data are redistributed. The catalogue outputs are derived gene-level model results without variant-level or participant-level source records.
